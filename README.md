## 🧭 Des petits trucs

Mes sujets de prédilection :

- **Infrastructure & plateformes** — Kubernetes, K3s, Docker, virtualisation et haute disponibilité.
- **Identité & accès** — Authentik, Keycloak, Active Directory, LDAP, Kerberos, OIDC et SAML.
- **Automatisation** — scripts, déploiement, configuration et intégration entre services.
- **Développement d’outils** — applications web et interfaces pour rendre les opérations techniques plus simples.
